# Exemples

Le registre inclut des composants d'exemple pour illustrer les bonnes pratiques et les patrons de conception.

## Hello World

Un composant minimal qui montre comment creer et distribuer un bloc d'interface simple.

```bash
npx shadcn@latest add @sntlr/hello-world
```

Ce composant illustre :

- La structure de base d'un composant
- L'utilisation des dependances du registre (Button)
- L'interactivite cote client

## Formulaire d'exemple

Un exemple plus complexe comportant un formulaire de contact avec validation.

```bash
npx shadcn@latest add @sntlr/example-form
```

Ce composant illustre :

- La gestion de l'etat du formulaire avec les hooks React
- La validation de schema avec Zod
- L'utilisation de plusieurs dependances du registre (Button, Input, Label, Textarea, Card)
- La gestion des erreurs et les etats de succes
